---
title: "List all surahs"
description: "Returns the full index of all 114 surahs."
api: "GET /surah"
---

Returns every surah with its number, Arabic name, Meccan/Medinan flag when
available, and the provider label that supplied the cached list.

## Endpoint

```http
GET /surah
```

## Response

```json
{
  "success": true,
  "data": {
    "surah": [
      { "id": 1, "name": "الفاتحة", "makkia": true, "apiName": "mp3quran.net" },
      { "id": 2, "name": "البقرة", "makkia": false, "apiName": "mp3quran.net" }
    ]
  }
}
```

## Notes

- Cached for **12 hours** under `surah:all`.
- Provider order: `mp3quran.net` -> `alquran.cloud` -> `quran.com`.
