---
title: "Service catalogue"
description: "Project metadata and the full list of registered routes."
api: "GET /"
---

Returns the service name, description, and the Fastify routes registered at
boot. The route list is built from Fastify's `onRoute` hook and excludes `/`
and `/health`.

## Endpoint

```http
GET /
```

## Response

```json
{
  "name": "Etha3a-API",
  "description": "Quran & Azkar API with multi-source fallback",
  "routes": [
    { "method": "GET", "url": "/surah" },
    { "method": "GET", "url": "/ayat/search" },
    { "method": "GET", "url": "/qibla" }
  ]
}
```

This endpoint does not use the standard `{ success, data }` envelope.
