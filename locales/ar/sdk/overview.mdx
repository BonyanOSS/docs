الحزمة الرسمية @bonyanoss/bonyan-api تدعم ESM وCommonJS وتحتوي أنواع TypeScript. تتطلب Node.js 22.12 أو أحدث. يمكن لتطبيقات المتصفح استخدام مجمع حزم وواجهات fetch وURL وAbortController.

إصدار SDK 2.0.0 متوفر على npm. تتحقق الوثائق من الأمثلة والتكامل مع API باستخدام نفس الإصدار المنشور.

```bash
npm install @bonyanoss/bonyan-api@2.0.0
```


```ts
import { BonyanClient } from '@bonyanoss/bonyan-api';

const client = new BonyanClient({ timeoutMs: 45000, retry: 1 });
const { total, results } = await client.ayat.search('الرحمن', { limit: 10 });
console.log(total, results[0]?.aya.text, results[0]?.apiName);
const azkar = await client.azkar.search('الله', { limit: 10 });
console.log(azkar.results[0]?.category, azkar.results[0]?.apiName);
```

تعيد دوال المحتوى data مباشرة، ودوال القوائم مصفوفة. يعيد البحث `{ total, results }`. تعيد دوال التشغيل كائن JSON مباشرًا وmetrics نصًا. createBonyanClient(options) يكافئ new BonyanClient(options).

## الهجرة من 1.0.2

أزل دالة البحث البديلة. استخدم muyassar أو saadi للتفسير؛ forSurah يعيد مصفوفة دائمًا. حدّث الأنواع التي تنشئها يدويًا لتشمل حقول المصحف والمصدر والمنطقة الزمنية والتقويم المطلوبة. حُذفت style وImsak وMidnight من العقد. بعض قيم apiName القديمة لم تعد مصادر مدعومة. اختيار moshaf وtimezone وخيارات الطلب إضافات اختيارية.
