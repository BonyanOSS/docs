---
title: "البحث باستخدام SDK"
description: "استجابات البحث وعدد النتائج وحالة عدم وجود تطابق."
---

يحافظ SDK 2.0.0 على استجابة API بالشكل `{ success: true, total, data: [...] }` ويعيد `{ total, results }`. استخدم دوال الموارد مباشرة؛ لم تعد الدالة البديلة الخاصة بالإصدار 1.0.2 مطلوبة.

```ts
import { BonyanClient } from '@bonyanoss/bonyan-api';

const client = new BonyanClient({ timeoutMs: 45000, retry: 1 });
const { total, results } = await client.ayat.search('الرحمن', { limit: 10 });
console.log(total, results[0]?.aya.text, results[0]?.apiName);
const azkar = await client.azkar.search('الله', { limit: 10 });
console.log(azkar.results[0]?.category, azkar.results[0]?.apiName);
```

الحد الافتراضي 50. يقبل بحث الآيات 1..500 وبحث الأذكار 1..200. يحسب total النتائج المعادة بعد الحد، ولا يمثل عدد التطابقات في المحتوى كله. لا يوجد ترقيم صفحات. عدم وجود نتائج يعيد HTTP 404 من خلال BonyanApiError. تحتوي النتائج apiName؛ ونتائج الأذكار تحتوي category وitem.

تقبل كل دالة خيارات النقل في المعامل الأخير. راجع [الإعدادات](/locales/ar/sdk/configuration) لاستخدام signal وtimeoutMs وheaders، و[البحث بالعربية](/locales/ar/concepts/arabic-search) لفهم التطبيع.

مثال دالة تطبيق تستخدم SDK مباشرة، دون فك غلاف مخصص:

```js
import { BonyanClient, ValidationError } from "@bonyanoss/bonyan-api";

// Application helper using the supported SDK search methods.
export async function searchContent(
  resource,
  text,
  {
    limit = 10,
    baseUrl = "https://api.bonyanoss.org",
    fetch = globalThis.fetch,
    signal = AbortSignal.timeout(45000),
  } = {},
) {
  if (!["ayat", "azkar"].includes(resource)) {
    throw new ValidationError("resource must be ayat or azkar", "resource");
  }
  const client = new BonyanClient({ baseUrl, fetch, timeoutMs: 45000, retry: 0 });
  return client[resource].search(text, { limit }, { signal });
}
```
