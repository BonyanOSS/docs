description: "الرابط والمهلة والمحاولات والترويسات وإلغاء الطلب."
---

```ts
import { BonyanClient } from '@bonyanoss/bonyan-api';

const client = new BonyanClient({ timeoutMs: 45000, retry: 1 });
const controller = new AbortController();
const pending = client.ayat.search('الله', { limit: 10 }, {
  signal: controller.signal,
  timeoutMs: 20000,
  headers: { 'X-Application': 'my-app' },
});
controller.abort();
await pending.catch(console.error);
console.log(await client.health({ timeoutMs: 2000 }));
```

| الخيار | الافتراضي |
| --- | --- |
| baseUrl | https://api.bonyanoss.org |
| timeoutMs | 10000 |
| retry | 3 |
| headers | Accept: application/json |
| fetch | globalThis.fetch |
| userAgent | غير محدد |

تقبل كل دالة BonyanRequestOptions في المعامل الأخير: signal وtimeoutMs وheaders. إذا كانت للدالة خيارات مثل limit أو moshaf، أرسلها أولًا. تقبل timeoutMs عددًا صحيحًا موجبًا حتى 2147483647، وتقبل retry عددًا صحيحًا غير سالب. تطبق المهلة لكل محاولة؛ استخدم signal لتحديد مهلة للعملية كاملة. الإلغاء يوقف الطلب الجاري وانتظار إعادة المحاولة، والإشارة الملغاة مسبقًا تمنع fetch.

تُدمج أسماء الترويسات دون حساسية لحالة الأحرف. يمكن أن يحتوي baseUrl بادئة بوابة؛ تُحذف الشرطات المائلة النهائية وتُلحق مسارات الموارد. سلوك User-Agent في المتصفح يعتمد على المنصة. لا يخزن SDK الاستجابات ولا يتحقق من كل حقل وقت التشغيل؛ يرفض غلاف النجاح أو البحث غير الصالح.
