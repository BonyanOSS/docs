متطلب خادم API هو Node.js 24 (`>=24 <25`)، ومدير الحزم pnpm 10.33.4. يستخدم SDK والوثائق إعداداتهما الخاصة. لا يحتاج الخادم قاعدة بيانات أو مفتاح API للمصادر، ويحتاج اتصال HTTPS صادرًا للمحتوى الخارجي.

## التشغيل المحلي

```bash
git clone https://github.com/BonyanOSS/Bonyan-API.git
cd Bonyan-API
corepack enable
corepack prepare pnpm@10.33.4 --activate
pnpm install --frozen-lockfile
pnpm dev
```

انسخ .env.example إلى .env قبل التشغيل: cp على Unix أو Copy-Item في PowerShell. الرابط المحلي http://localhost:3000 دون بادئة إصدار. المتغيرات PORT وHOST للاستماع، وRATE_LIMIT_MAX وRATE_LIMIT_WINDOW لميزانية الطلبات، وCORS_ORIGIN لقائمة النطاقات، وTRUST_PROXY لثقة البروكسي، وLOG_LEVEL للسجلات، وCACHE_MAX_ENTRIES لسعة الكاش. يفعّل TRUST_PROXY النص true فقط؛ استخدمه خلف بروكسي موثوق.

```bash
pnpm lint:check
pnpm test
pnpm build
pnpm start
```

## Docker

يستخدم Dockerfile صورة Node 24 Alpine ويشغّل dist/server.js. لاختباره:

```bash
docker build -t bonyan-api .
docker run --rm -p 3000:3000 --env-file .env bonyan-api
```

## Cloudflare Workers

يستخدم النشر src/worker.ts بمحول Fetch أصلي وعلم nodejs_compat، دون Fastify داخل Worker ودون حاوية. يضبط wrangler.toml تاريخ التوافق 2026-10-04 والنطاق المخصص api.bonyanoss.org، مع preview_urls=true وworkers_dev=false. إعدادات البيئة في Worker تمر عبر bindings؛ لا تستمع PORT وHOST إلى منفذ داخله.

```bash
pnpm cloudflare:check
pnpm cloudflare:startup
pnpm deploy:cloudflare
```

يختبر الأمر الأول حزمة النشر دون نشر، ويختبر الثاني بدء Worker عبر /health و/ready و/tafsir. أمر deploy يتطلب حساب Cloudflare ونطاقًا مهيأ. تحذف هجرة v2 فئة الحاوية القديمة؛ أبقِ سجل الهجرات للنشر القائم.

فحوص /health و/ready لا تتصل بالمصادر. أضف طلب محتوى عند اختبار توفرها، واقرأ /metrics كنص. الكاش والحدود خاصان بكل عملية أو عزل Worker. راجع [التشغيل](/locales/ar/guides/operations).
