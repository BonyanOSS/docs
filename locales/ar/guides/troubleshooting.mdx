| المشكلة | التحقق والإجراء |
| --- | --- |
| كل الطلبات 404 | استخدم https://api.bonyanoss.org دون بادئة /bonyan-api/v1. |
| التفسير 400 | استخدم muyassar أو saadi؛ استخرج القائمة من /tafsir. |
| بحث SDK يعيد undefined | حدّث إلى الإصدار 2.0.0؛ راجع دليل التثبيت. |
| البحث الإنجليزي يطابق نتائج غير مقصودة | استخدم نصًا عربيًا ذا معنى؛ قد يصبح الاستعلام اللاتيني فارغًا بعد التطبيع. |
| الصوت 404 | تحقق من ملكية moshaf للقارئ وتغطية surahList للسورة. |
| الصوت 503 | فشل فحص HEAD لدى جميع المصادر المتاحة. |
| فشل تشغيل رابط ناجح | افحص طلب الصوت في المتصفح؛ قد تغير المصدر بعد فحص API. |
| توقيت الصلاة غير متوقع | افحص timezone وmethod؛ الافتراضي UTC والطريقة 4. |
| الصلاة باسم مدينة 503 | المصدر غير متاح؛ جرب إحداثيات لتفعيل الحساب المحلي. |
| الكتاب 404 | تحقق من معرّف الكتاب؛ وقد تكون فجوة الترقيم سبب غياب حديث. |
| health ناجح والمحتوى يفشل | health لا يفحص المصادر؛ افحص المسار ومعرّف الطلب والمقاييس. |

أرفق المسار والمعاملات وحالة HTTP ومعرّف الطلب وإصدار SDK ومثالًا مختصرًا عند الإبلاغ. راجع [تثبيت SDK](/locales/ar/sdk/overview).
