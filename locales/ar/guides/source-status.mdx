تمت المراجعة في 4 أكتوبر 2026.

| المصدر | الإصدار | دليل المراجعة |
| --- | --- | --- |
| حزمة API | 2.1.0 | [c851b1a](https://github.com/BonyanOSS/Bonyan-API/tree/c851b1a) |
| عقد OpenAPI | 3.0.0 | العقود الجديدة في OpenAPI وسجل تغييرات API. |
| SDK | 2.0.0 | [667e5b0](https://github.com/BonyanOSS/bonyan-sdk-js/tree/667e5b0)، وإصدار npm وبصمة الحزمة. |
| الوثائق | 1.1.0 | عقود مولدة باللغتين وفحوص تكامل. |

تختلف تسمية الحزمة 2.1.0 عن تسمية العقد 3.0.0 في مستودع API الحالي. تحفظ الوثائق التسميتين وتصف المتحكمات الفعلية عند c851b1a. لا تضيف أي منهما بادئة للمسار. لا تكشف فحوص الخدمة العامة عن كوميت، فلا تثبت مطابقة النسخة المنشورة لهذا المصدر.

إصدار SDK 2.0.0 منشور على npm من الكوميت المدمج 667e5b0. تثبّت الوثائق نفس الإصدار. تحفظ sources.lock.json بصمة المصدر وبصمة الحزمة في السجل، ويثبّت pnpm-lock.yaml الأرشيف المستخدم.

يصلح التحديث فك غلاف البحث ويطابق أنواع الاستجابات ويضيف moshaf وtimezone وإلغاء الطلب لكل دالة. يدعم التفسير muyassar وsaadi فقط. يقبل نطاق الحديث 300 رقم شامل الطرفين، وقد يحتوي الترقيم على فجوات. راجع [الهجرة](/locales/ar/sdk/overview) و[الصيانة](/locales/ar/guides/maintenance).
