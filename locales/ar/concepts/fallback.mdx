---

تُجرب المصادر بالتتابع عند غياب الكاش. تتحقق المحولات من التغطية والهوية والحقول المطلوبة قبل قبول البيانات؛ النتيجة الفارغة أو غير الصالحة تؤدي لتجربة المصدر التالي. فشل جميع المصادر يعيد 503. إعادة المحاولة في SDK تكرر طلب API وهي مستقلة عن هذا السلوك.

| الوحدة | ترتيب المصادر |
| --- | --- |
| السور | mp3quran.net ثم alquran.cloud ثم quran.com ثم البيانات المحلية الثابتة. |
| الآيات | alquran.cloud ثم نسخة fawazahmed0 المثبتة عبر jsDelivr ثم quran.com. |
| فهرس القراء | mp3quran.net ثم النسخة المحلية التي تحافظ على المعرّفات والمصاحف. |
| الصوت | رابط mp3quran المفحوص، ثم تسجيل Quran.com المطابق عند وجود ربط موثق. |
| التفسير | muyassar: alquran.cloud ثم quranenc.com ثم quran.com ثم مرآة spa5k المثبتة. saadi: quran.com ثم مرآة spa5k. |
| الأذكار | نسخة rn0x/hisn_almuslim_json المثبتة عبر jsDelivr ثم GitHub الخام. |
| الحديث | فهرس كتب محلي؛ المحتوى من نسخة gadingnst المثبتة عبر jsDelivr ثم GitHub الخام. |
| الصلاة | Aladhan ثم adhan محلي للإحداثيات. طلب المدينة وحده لا يملك بديلًا محليًا. |
| الهجري | Aladhan UAQ مع مطابقته لتحويل islamic-umalqura المحلي، ثم Intl محلي. |
| القبلة | Aladhan ثم حساب الاتجاه محليًا. |

استخدم apiName لمعرفة المصدر. تحافظ البدائل المدعومة على أسماء السور الثابتة وهويات القراء ومعرّفات التفسير العامة وتاريخ الصلاة وطريقتها ومنطقتها الزمنية وتقويم أم القرى. تبقى الحقول الاختيارية اختيارية: مصدر الأذكار الحالي يوفر النص دون عدد التكرار أو المرجع، وقد تحذف الصلاة المحلية hijri.

مهلة الاتصال الافتراضية 8 ثوان، وقد تصل إلى 30 ثانية لكتاب حديث. قد يتجاوز تعدد المصادر والصفحات مهلة SDK الافتراضية البالغة 10 ثوان للمحاولة. اختر مهلة مناسبة للتحميل الأول واستخدم الإلغاء لتحديد مدة العملية كاملة.
