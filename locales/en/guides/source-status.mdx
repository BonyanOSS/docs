The hosted probes do not expose a commit, so repository compatibility does not establish the live deployment revision.

SDK 2.0.0 is published on npm from merged commit 667e5b0. The docs install this exact release. sources.lock.json records the reviewed source hash and registry distribution integrity; pnpm-lock.yaml pins the installed archive.

The update fixes flat search decoding, aligns normalized response types, adds moshaf and timezone options, and makes transport cancellation available on every method. Only muyassar and saadi are supported. Hadith ranges accept 300 inclusive numbers; gaps are allowed. See [migration](/locales/en/sdk/overview) and [maintenance](/locales/en/guides/maintenance).
