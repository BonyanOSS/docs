---
title: "Troubleshooting"
description: "Identify configuration, provider and playback failures."
---

| Symptom | Check and action |
| --- | --- |
| Every request returns 404 | Use https://api.bonyanoss.org without /bonyan-api/v1. |
| Tafsir returns 400 | Use muyassar or saadi; discover IDs through /tafsir. |
| SDK search gives undefined fields | Upgrade to 2.0.0; see installation guidance. |
| English search matches unrelated entries | Use meaningful Arabic; Latin-only input can normalize to empty. |
| Audio returns 404 | Check that moshaf belongs to the reciter and surahList covers the surah. |
| Audio returns 503 | All eligible sources failed the HEAD check. |
| A successful audio URL fails playback | Inspect the browser audio request; availability can change after API verification. |
| Prayer time seems wrong | Inspect timezone and method; defaults are UTC and method 4. |
| City prayer request returns 503 | The provider is unavailable; use coordinates for local calculation. |
| Hadith returns 404 | Verify the book ID; numbering gaps can explain missing narrations. |
| Health succeeds but content fails | Health does not probe providers; inspect the route, request ID and metrics. |

Include the route/query, HTTP status, request ID, SDK version and a minimal example when reporting an issue. See [SDK installation](/locales/en/sdk/overview).
