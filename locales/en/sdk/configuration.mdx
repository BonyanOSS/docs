---
title: "Client and request configuration"
description: "Base URL, timeouts, retries, headers and cancellation."
---

```ts
import { BonyanClient } from '@bonyanoss/bonyan-api';

const client = new BonyanClient({ timeoutMs: 45000, retry: 1 });
const controller = new AbortController();
const pending = client.ayat.search('الله', { limit: 10 }, {
  signal: controller.signal,
  timeoutMs: 20000,
  headers: { 'X-Application': 'my-app' },
});
controller.abort();
await pending.catch(console.error);
console.log(await client.health({ timeoutMs: 2000 }));
```

| Option | Default |
| --- | --- |
| baseUrl | https://api.bonyanoss.org |
| timeoutMs | 10000 |
| retry | 3 |
| headers | Accept: application/json |
| fetch | globalThis.fetch |
| userAgent | Unset |

Every method accepts BonyanRequestOptions as its final argument: signal, timeoutMs and headers. Pass domain options such as limit or moshaf first. timeoutMs must be a positive integer up to 2147483647; retry must be a nonnegative integer. The timeout applies per attempt. Use a signal for a total deadline. Cancellation stops an active request or retry delay; an already aborted signal prevents fetch.

Header names merge case-insensitively. baseUrl can include a gateway prefix; trailing slashes are removed and resource paths appended. Browser User-Agent behavior is platform-dependent. The SDK has no response cache and does not validate every response field at runtime; malformed success or search envelopes are rejected.
