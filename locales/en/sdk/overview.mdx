The official @bonyanoss/bonyan-api package supports ESM and CommonJS with TypeScript declarations. Node.js 22.12 or later is supported. Browser applications can use a bundler and fetch, URL and AbortController APIs.

SDK 2.0.0 is available on npm. These docs check examples and API integration against that exact published version.

```bash
npm install @bonyanoss/bonyan-api@2.0.0
```


```ts
import { BonyanClient } from '@bonyanoss/bonyan-api';

const client = new BonyanClient({ timeoutMs: 45000, retry: 1 });
const { total, results } = await client.ayat.search('الرحمن', { limit: 10 });
console.log(total, results[0]?.aya.text, results[0]?.apiName);
const azkar = await client.azkar.search('الله', { limit: 10 });
console.log(azkar.results[0]?.category, azkar.results[0]?.apiName);
```

Content methods return data directly, and lists return arrays. Search returns `{ total, results }`. Operational methods return raw JSON and metrics returns text. createBonyanClient(options) equals new BonyanClient(options).

## Migration from 1.0.2

Remove the search adapter. Use muyassar or saadi for tafsir; forSurah always returns an array. Update manually constructed types to include required recording, provenance, timezone and calendar metadata. style, Imsak and Midnight are removed from the contract. Old apiName values no longer describe supported sources. moshaf selection, timezone and per-call transport options are optional additions.
