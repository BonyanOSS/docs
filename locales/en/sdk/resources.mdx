---
title: "SDK method reference"
description: "Resource methods, signatures and return types."
---

Every method below is called on `client` and returns a Promise of the listed type. `?` denotes an optional argument or option; table signatures are shorthand, not copyable code.

Numeric arguments are JavaScript numbers; names, queries, book IDs and edition IDs are strings. Dates use `DD-MM-YYYY`. prayer.getTimes accepts coordinates or city/country, plus optional date and method.

<Warning>
The ayat and azkar search methods in 1.0.2 do not match the current API envelope. Their declared types do not make their runtime result valid. [Search adapter](/locales/en/sdk/search).
</Warning>
